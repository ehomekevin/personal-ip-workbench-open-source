# 开发入口

这是本地优先的工作台：浏览器与宿主插件通过 HTTP 调用本地服务，领域层处理业务规则，SQLite 保存状态，受管目录保存正文和媒体。演示模式与真实模式在首次创建工作区时选择；真实模式不等于已经配置外部服务。

## 代码与契约

- `apps/web`：React 页面、真实 HTTP client 和演示数据。
- `apps/service`：配置校验、独占启动锁、HTTP 路由与后台任务。
- `apps/mcp`、`plugins`：宿主入口和共享界面；通过连接描述符访问已经运行的本地服务，不携带数据库或启动生产服务。
- `packages/contracts/src/resources.ts`：资源注册表；每项的 `implementation_path` 指向对应实现。
- `packages/contracts`：输入输出类型、错误码和版本；变更协议时同时检查对应服务路由与客户端。
- `packages/domain`：写作、资料、任务、制作、排期和复盘规则。内置写作、语音整理、配图规划规则随源码分发；任务冻结正文与哈希，恢复不替换已冻结输入。
- `packages/storage/migrations`：SQLite 迁移的可执行定义；`packages/storage/src/schema/registry.json` 提供表和约束索引。迁移按顺序校验历史 checksum，不直接覆盖旧迁移。
- `packages/adapters`：原生执行器、媒体工具与平台适配。接口实现或单元测试通过不代表真实凭据、宿主或平台发布已验证。

## 持久化与任务

工作区使用独立的配置、SQLite、正文和媒体目录。存储目录必须已经存在、可写且是规范的绝对物理路径；拒绝符号链接与缺失的外置挂载，不自动回退。服务启动负责创建选定目录、执行迁移和恢复已登记状态。

写操作绑定工作区、服务实例与幂等键；版本冲突由调用方重新读取处理。外部提交的结果未知时保留原任务及回执，查询恢复不能冒充新的授权提交。用户采用、文档修订和发布状态分别持久化。

## 测试与扩展

安装、初始化和主要验证命令见根 README。`tests/foundation` 覆盖迁移与契约，`tests/bootstrap` 覆盖真实启动和锁，`tests/ci` 覆盖可移植业务规则，`tests/e2e` 覆盖浏览器流程。测试使用合成资料和隔离目录；测试日志、数据库、截图与真实 provider 回执不属于源码分发。

新增适配器时保留未配置、受限与结果未知状态，不能因存在实现就宣称真实能力通过。配置和运行产生的凭据只留在用户本机。新 UI 资源使用 `apps/web/public/workbench`，新增内置文件需加入分发检查。
